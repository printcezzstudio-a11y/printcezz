# 🖨️ Printcezz

เว็บร้านปริ้นท์ครบวงจร (นามบัตร สติกเกอร์ โปสเตอร์ ป้ายไวนิล ใบปลิว) พร้อมระบบจัดการคำสั่งซื้อสำหรับแอดมิน

เป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไรเพิ่ม เปิดใช้งานได้เลย

## ฟีเจอร์

- **หน้าแรก / ปฏิทินปิดรับไฟล์งาน / คำนวณราคา** (ราคาลดตามจำนวนอัตโนมัติ)
- **ตรวจคำสั่งซื้อ** ลูกค้ากรอกรหัสคำสั่งซื้อเพื่อดูสถานะและคิว
- **แผงแอดมิน**
  - จัดการคำสั่งซื้อ แยกตาม "ดำเนินการอยู่ / รอจัดส่ง / เสร็จแล้ว"
  - ค้นหาคำสั่งซื้อตามรหัสหรือชื่อลูกค้า
  - คำสั่งซื้อที่เสร็จแล้วจัดเป็นรายปี → รายเดือน พร้อมสรุปรายได้ ต้นทุน กำไร
  - จัดการปฏิทิน สินค้า/ราคา ตกแต่งหน้าแรก และตั้งค่า

## วิธีขึ้นเว็บด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Public)
2. อัปโหลดไฟล์ `index.html` และ `README.md` ไปที่ repository (ปุ่ม **Add file → Upload files**)
3. ไปที่ **Settings → Pages**
4. ตรง **Build and deployment** เลือก **Source: Deploy from a branch**
5. เลือก Branch เป็น `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1–2 นาที เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repository>/`

## การเข้าแอดมิน

พิมพ์รหัสผ่านแอดมินลงในช่อง "กรอกหมายเลขคำสั่งซื้อ" ที่หน้า **ตรวจคำสั่งซื้อ** แล้วกด "ตรวจสอบ" จะเข้าสู่แผงแอดมิน
รหัสผ่านเริ่มต้นคือ `1234` เปลี่ยนได้ที่ **แอดมิน → ตั้งค่า**

## ข้อควรรู้เรื่องข้อมูล

- ข้อมูลทั้งหมด (คำสั่งซื้อ สินค้า รูปภาพ) เก็บอยู่ใน **เบราว์เซอร์ของแต่ละเครื่อง** (localStorage) ไม่ได้อยู่บน GitHub และไม่ถูกแชร์ข้ามเครื่อง
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย ควรกด **แอดมิน → ตั้งค่า → ดาวน์โหลดข้อมูล (JSON)** เพื่อสำรองไว้เป็นระยะ
- การแก้ไขข้อมูลร้านในเว็บจะไม่เปลี่ยนไฟล์ใน GitHub ถ้าต้องการเปลี่ยนค่าเริ่มต้นของเว็บ ให้แก้ที่ไฟล์ `index.html` โดยตรง
